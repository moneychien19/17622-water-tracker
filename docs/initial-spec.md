# Water Tracker

This is an application which helps user track watering activities and coordinate shared care.

## Problem

A user might want to take care of plants with others, and each plant has different needs.

## Requirements

### Functional Requirements

- The application should contain a dashboard showing what needs attention would be useful. Maybe something that clearly shows which plants need watering and which ones are still outside. Notifications would be nice too, but I don't think we need those immediately.
- Live update. Whenever someone waters the plant, the schedule should be updated immediately.
- Login and authentication.
